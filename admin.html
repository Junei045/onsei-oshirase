お知らせを登録する

  1. 音声ファイルを GitHub の audio フォルダ にアップロードして Commit changes
  2. 1〜2分待ってから、下の「再読み込み」を押す
  3. ファイルを選び、見出しと本文を入れて公開する

一覧に大きく表示されます。60文字まで。

音声を再生できない方はこの文章を読みます。音声と同じ内容にしてください。

ファイル名は半角英数字にしてください（例: 20260802-natsumatsuri.m4a）。

緊急のお知らせは必ず設定してください。過ぎると自動的に一覧から消えます。
