# audio

音声ファイルはこのフォルダに置きます。

## 決まりごと

- ファイル名は**半角英数字とハイフンのみ**。日本語や空白は使わないでください
- 「日付＋内容」の形にすると探しやすくなります
  - 例: `20260802-natsumatsuri.m4a`
  - 例: `20260915-shigen-kaishu.m4a`
- 形式は m4a / mp3 / wav
- 1ファイル 20MB 以内、長さは2分以内を目安に

## 手順

1. このフォルダを開いて **Add file → Upload files**
2. 音声ファイルをドラッグ＆ドロップ
3. **Commit changes** を押す
4. 1〜2分待ってから管理画面（admin.html）の「再読み込み」を押す

管理画面で一覧から削除しても、ここのファイルは残ります。不要になったファイルは
GitHub 上で手動で削除してください（過去のお知らせを残しておきたい場合はそのままで構いません）。
